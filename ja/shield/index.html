Canonic Shield

コーディングエージェント向けのプロジェクト権限。

Shield は、Claude Code や Codex が送信するコマンド、ファイルの読み取り、Web リクエストをプロジェクトのルールと照合します。結果は許可、確認、拒否のいずれかで、判定に使われたルールも表示します。

はじめるガイドを読む
プロジェクト内で
shield init
shield status
shield doctor
プロジェクトポリシー

確認できるルールから始めましょう。

shield init は署名付きの基本パックをインストールし、エージェントを接続します。Loose、Recommended、Strict のいずれかを選び、変更を確認して承認してください。

使うツールの権限パックを追加したり、コマンド、引数、パス、Web アドレスについて詳細なルールを YAML や JSON で書いたりできます。エージェントから提案された変更は、あなたの承認が必要です。

権限パック
shield pack search node
shield pack add node --profile strict
shield pack update
インストール

Rust 製のコマンドラインツールをソースからビルドします。

Shield はまだパッケージマネージャーで配布されていません。Rust をインストールし、リポジトリをクローンして CLI をビルドします。ツールチェーンのバージョンはリポジトリで固定されています。

macOS と Linux では、このコマンドで shield が ~/.local/bin にインストールされます。このフォルダーを PATH に追加してください。Windows 向けのソースビルドは、プロジェクトの登録と Claude Code および Codex のフックに対応しています。 Windows でのインストール

Shield は送信されたリクエストを確認します。エージェントのサンドボックスを置き換えるものではなく、ホストがフックを呼び出さない場合はルールが適用されません。 Shield とは？

ターミナル
git clone https://github.com/canonic2/canonic.git
cd canonic/packages/shield
cargo xtask install
