Canonic Shield

Projectmachtigingen voor programmeeragents.

Shield controleert de opdrachten, bestandstoegang en webverzoeken van Claude Code en Codex aan de hand van de regels in je project. Per verzoek zie je of het wordt toegestaan, om bevestiging vraagt of wordt geweigerd, met de regels die dit bepalen.

Aan de slagLees de handleidingen
In je project
shield init
shield status
shield doctor
Projectbeleid

Begin met regels die je kunt controleren.

shield init installeert een ondertekend basispakket en koppelt je agents. Kies Loose, Recommended of Strict, controleer de wijzigingen en bevestig ze.

Voeg machtigingspakketten toe voor je gereedschappen of schrijf precieze YAML- of JSON-regels voor opdrachten, argumenten, paden en webadressen. Agents kunnen regels voorstellen en jij bevestigt wijzigingen.

Machtigingspakketten
shield pack search node
shield pack add node --profile strict
shield pack update
Installatie

Bouw één Rust-opdrachtregelprogramma vanuit broncode.

Shield is nog niet beschikbaar via pakketbeheerders. Installeer Rust, kloon de repository en bouw de CLI. De repository legt de toolchain vast.

Op macOS en Linux installeert de opdracht shield in ~/.local/bin. Voeg die map toe aan je PATH. Windows-builds uit de broncode ondersteunen projectregistratie en hooks voor Claude Code en Codex. Installatie op Windows

Shield controleert ingediende verzoeken. Het vervangt de sandbox van de agent niet. De regels worden niet afgedwongen als de host de hooks overslaat. Wat is Shield?

Terminal
git clone https://github.com/canonic2/canonic.git
cd canonic/packages/shield
cargo xtask install
