Canonic Shield

Project permissions for coding agents.

Shield checks the commands, file reads and web requests that Claude Code and Codex submit against rules you keep with your project. Each request gets Allow, Ask or Deny, with the rules that decided it.

Get startedRead the guides
In your project
shield init
shield status
shield doctor
Project policy

Start with rules you can review.

shield init installs a signed baseline pack and connects your agents. Pick a Loose, Recommended or Strict profile, then review and confirm the changes.

Add permission packs for the tools you use, or write precise YAML or JSON rules for commands, arguments, paths and web addresses. Agents can propose rules; changes need your confirmation.

Permission packs
shield pack search node
shield pack add node --profile strict
shield pack update
Install

Build one Rust CLI from source.

Shield has not been published to package managers yet. Install Rust, clone the repository and build the CLI. The checkout pins its toolchain.

The command installs shield into ~/.local/bin; add that folder to your PATH. macOS is the verified platform. Native agent setup uses Unix hooks and refuses Windows.

Shield checks submitted requests. It does not replace the agent's sandbox, and a host that skips its hooks bypasses enforcement. See What is Shield?

Terminal
git clone https://github.com/canonic2/canonic.git
cd canonic
make -C packages/shield install-local
