Canonic Shield

为编程代理管理项目权限。

Shield 按项目中的规则检查 Claude Code 和 Codex 提交的命令、文件读取和网络请求。每个请求都会得到允许、询问或拒绝的结果，并显示决定结果的规则。

开始使用阅读指南
在项目中
shield init
shield status
shield doctor
项目策略

从可审查的规则开始。

shield init 安装签名的基础权限包并连接你的代理。选择 Loose、Recommended 或 Strict 配置，然后审查并确认更改。

添加所用工具的权限包，或用 YAML 或 JSON 为命令、参数、路径和网址编写精确规则。代理可以提出规则，更改需要你确认。

权限包
shield pack search node
shield pack add node --profile strict
shield pack update
安装

从源码构建一个 Rust 命令行工具。

Shield 尚未发布到软件包管理器。安装 Rust，克隆仓库并构建命令行工具。仓库固定了工具链版本。
