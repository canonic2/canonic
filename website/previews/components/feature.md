# Feature

One feature on the overview: a kicker and heading over its text, in the
default slot, beside its media, in the `media` slot: a screenshot figure or a
code sample.

| Prop | Type | Description |
| --- | --- | --- |
| `id` | string | The section's ID, for links to it |
| `kicker` | string | The short line above the heading |
| `title` | string | The heading |

## With a code sample

```example code-sample
caption: kicker="States" title="Pages with several states"
```
