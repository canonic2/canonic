Canonic Shield

Projektberechtigungen für Coding-Agenten.

Shield prüft Befehle, Dateizugriffe und Webanfragen von Claude Code und Codex anhand der Regeln in Ihrem Projekt. Jede Anfrage wird erlaubt, zur Bestätigung vorgelegt oder abgelehnt. Die entscheidenden Regeln werden angezeigt.

Erste SchritteAnleitungen lesen
In Ihrem Projekt
shield init
shield status
shield doctor
Projektrichtlinie

Beginnen Sie mit Regeln, die Sie überprüfen können.

shield init installiert ein signiertes Basispaket und verbindet Ihre Agenten. Wählen Sie Loose, Recommended oder Strict und bestätigen Sie die Änderungen nach der Prüfung.

Fügen Sie Berechtigungspakete für Ihre Werkzeuge hinzu oder schreiben Sie genaue YAML- oder JSON-Regeln für Befehle, Argumente, Pfade und Webadressen. Agenten können Regeln vorschlagen, Änderungen erfordern Ihre Bestätigung.

Berechtigungspakete
shield pack search node
shield pack add node --profile strict
shield pack update
Installation

Bauen Sie ein Rust-Kommandozeilenwerkzeug aus dem Quellcode.

Shield ist noch nicht über Paketmanager erhältlich. Installieren Sie Rust, klonen Sie das Repository und bauen Sie das Kommandozeilenwerkzeug. Das Repository legt die Toolchain fest.

Unter macOS und Linux installiert der Befehl shield in ~/.local/bin. Fügen Sie den Ordner zu Ihrem PATH hinzu. Aus dem Quellcode erstellte Windows-Builds unterstützen die Projektregistrierung sowie Hooks für Claude Code und Codex. Installation unter Windows

Shield prüft eingereichte Anfragen. Es ersetzt die Sandbox des Agenten nicht. Überspringt der Host die Hooks, greifen die Regeln nicht. Was ist Shield?

Terminal
git clone https://github.com/canonic2/canonic.git
cd canonic/packages/shield
cargo xtask install
