# Page hero

The top of an inner page: a kicker, the page's one `<h1>`, and a lede in the
default slot.

| Prop | Type | Description |
| --- | --- | --- |
| `kicker` | string | The short line above the heading |
| `title` | string | The page's heading |
| `width` | `narrow` or `narrower` | The text column's width. Defaults to `narrow`. |

## Narrow

```example narrow
caption: width="narrow"
```

The Install page's hero.

## Narrower

```example narrower
caption: width="narrower"
```

The Changelog's hero.
