# Section head

A section's kicker and heading, with an optional lede in the default slot, as
the overview uses it.

| Prop | Type | Description |
| --- | --- | --- |
| `kicker` | string | The short line above the heading |
| `title` | string | The heading |

## With a lede

```example with-lede
caption: kicker="Interface" title="Layout"
```

## Without a lede

```example without-lede
caption: kicker="Interface" title="Layout"
```
